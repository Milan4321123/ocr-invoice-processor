# Invoice OCR Processing System

A modern invoice management system with PDF upload, OCR processing, and validation.

## Project Overview

This application allows users to:
- Upload PDF invoices via a drag-and-drop interface
- Store and organize invoice documents
- Process invoices with OCR (future feature)
- View and manage invoice data through a dashboard

## Technology Stack

- **Frontend**: Next.js 14 (App Router), React, TypeScript, Tailwind CSS
- **Backend**: FastAPI (Python 3.11)
- **Storage**: Supabase (Files and Database)
- **Development**: Docker Compose for local development
