# Invoice OCR Frontend

Next.js frontend for the Invoice OCR Processing System.

## Setup

This is a scaffold placeholder. The Next.js project will be initialized with:

```bash
npx create-next-app@latest . --ts --tailwind --src-dir --app
```

## Features (Planned)

- PDF upload with drag-and-drop interface
- Filename validation with regex patterns
- Dashboard to view uploaded invoices
- Real-time upload progress
- Preview of processed OCR data
- Responsive design with Tailwind CSS

## Technology Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
- React Dropzone
- React Hot Toast
- Supabase client
